# さくらのレンタルサーバ 設置・アップロードガイド

本リポジトリのゆとシートⅡ（全対応システム：アフターアーカイブ、ソードワールド2.0/2.5、ビーストバインドトリニティ、キズナバレット、ダブルクロス The 3rd、アリアンロッド2E、マージナルシグナル、ガーデンオーダー、グランクレスト、ヴィジョンコネクト等）を「さくらのレンタルサーバ」に設置する手順です。

---

## 1. サーバーパス情報（確認・設定済み）
さくらのレンタルサーバの標準環境に合わせて全ファイルを調整済みです。

| 項目 | パス | 備考 |
|---|---|---|
| **Perl** | `/usr/bin/perl` | 全システムの `.cgi` ファイルの1行目（Shebang）に指定済み |
| **sendmail** | `/usr/sbin/sendmail` | `_core/lib/config-default.pl` に指定済み |
| **ImageMagick** | `/usr/local/bin/convert` | 画像変換用 |

---

## 2. ディレクトリ構成と設定状況

全システムディレクトリに対して、さくらのレンタルサーバ用 `.htaccess` およびデータ保護用 `.htaccess` を配置済みです。

```text
/home/ユーザー名/www/
  ├── ytsheet2/               ← （任意の設置フォルダ名）
  │    ├── .htaccess          ← （CGI実行ディレクティブ設定済み）
  │    ├── _core/             ← 必須（ゆとシートⅡ コアシステム）
  │    │    ├── data/         ← （アクセス拒否 .htaccess 配置済み）
  │    │    ├── lib/
  │    │    ├── module/
  │    │    └── skin/
  │    │
  │    ├── aa/                ← アフターアーカイブ
  │    │    ├── data/         ← （アクセス拒否 .htaccess 配置済み / パーミッション: 707 または 777）
  │    │    ├── .htaccess     ← （CGI実行ディレクティブ設定済み）
  │    │    ├── index.cgi     ← （パーミッション: 705 または 755）
  │    │    ├── oauth.cgi     ← （パーミッション: 705 または 755）
  │    │    └── config.cgi
  │    │
  │    ├── sw2.5/             ← ソードワールド2.5（同様に設定済み）
  │    ├── sw2.0/             ← ソードワールド2.0（同様に設定済み）
  │    ├── blp/               ← ブラッドパス（同様に設定済み）
  │    ├── kiz/               ← キズナバレット（同様に設定済み）
  │    ├── dx3rd/             ← ダブルクロス3rd（同様に設定済み）
  │    ├── ar2e/              ← アリアンロッド2E（同様に設定済み）
  │    ├── ms/                ← マージナルシグナル（同様に設定済み）
  │    ├── gs/                ← ゴブリンスレイヤー（同様に設定済み）
  │    ├── gc/                ← グランクレスト（同様に設定済み）
  │    └── vc/                ← ヴィジョンコネクト（同様に設定済み）
```

---

## 3. パーミッション（属性）設定一覧

FTPクライアント（FileZilla, FFFTP, WinSCP等）で以下のパーミッションに設定してください。

| 対象 | 推奨パーミッション | 備考 |
|---|---|---|
| **CGIファイル** (`*.cgi`) | **`705`** または **`755`** | 実行権限（rwx---r-x 等）<br>※`777` にすると500エラーになります |
| **データディレクトリ** (`*/data/`, `*/data/chara/` 等) | **`707`** または **`777`** | CGIからの書き込み権限 |
| **一般ディレクトリ** (`_core/`, 各システムフォルダ等) | **`705`** または **`755`** | 通常のディレクトリ権限 |
| **設定・プログラムファイル** (`*.pl`, `*.pm`, `*.html`, `*.css`, `*.js`, `config.cgi`) | **`604`** または **`644`** | 読み取り権限 |

---

## 4. 改行コードについて
すべてのプログラムファイル（`.cgi`, `.pl`, `.pm`, `.html`, `.css`, `.js`, `.txt`, `.default`）の改行コードは **LF（Unix形式）** に一括統一済みです。
FTPソフトでアップロードする際は、**バイナリモード（または自動判別）**でそのままアップロードしてください。

---

- **ダブルクロス3rd**: `http://(お客様のドメイン)/ytsheet2/dx3rd/`
- **アリアンロッド2E**: `http://(お客様のドメイン)/ytsheet2/ar2e/`
